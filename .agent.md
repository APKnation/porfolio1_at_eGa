# Repository Hygiene Agent

Use this agent when managing repository ignore rules, environment files, and custom project configuration.

## Instructions

- Always treat `.env` and any `.env.*` files as private. Do not commit actual secrets or credentials.
- Ensure local and generated files are ignored before pushing to GitHub.
- Add or update `.gitignore` rules for backend `venv/`, frontend `node_modules/`, `db.sqlite3`, editor metadata, system files, and environment files.
- When creating `.env`, include placeholder variable names and comments only.
- Do not store secret values in repository files.
- Keep this agent focused on repo hygiene, ignore file maintenance, and safe configuration generation.
